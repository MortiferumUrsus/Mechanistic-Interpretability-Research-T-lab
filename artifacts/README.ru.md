# Поправка направления стиринга для GPT-2 small

Этот репозиторий содержит артефакты исследования стиринга по признакам SAE в резидуале
GPT-2 small после шестого блока. Основной артефакт — обученная поправка направления

```text
w(v) = normalise(v + A Bᵀv)
```

Ранг матриц — 64, всего 98 304 параметра. При интервенции `h + s·w(v̂)` норма возмущения совпадает
с нормой наивного варианта `h + s·v̂`, поэтому сравнение отражает смену направления, а не скрытый
рост силы стиринга.

## Что она делает и чего не делает

На отложенных признаках SAE поправка доставляет целевой признак сильнее, чем столбец декодера, при
той же норме возмущения: доля попаданий по собственному словарю признака растёт примерно на 0.3–0.4
при равной силе — на исходном тестовом наборе, на двенадцати признаках, удержанных вне обучения, и
на 48 свежих признаках. Она также снижает Pythia log-перплексию сгенерированного текста примерно
на 1.1–1.4 ната.

Выигрыш по перплексии не следует читать как выигрыш по связности. Примерно половина того, что
поправка добавляет к любому признаку, — одно общее направление, которое снижает энтропию следующего
токена; инжектированное само по себе, оно снижает перплексию генерации сильнее, чем полная поправка,
не доставляя никакого концепта, и при этом ухудшает предсказание настоящего текста моделью. Слепой
аудит генераций одним LLM-аннотатором также подтверждает прирост концепта, но находит больше
дегенерации и не показывает улучшения по coherence. Измеренная на отложенном настоящем тексте при
равной доставке концепта, поправка снижает повреждение от стиринга, потому что доставляет концепт на
меньшей силе; величина этого снижения (0.1–0.6 ната NLL при teacher forcing) определена неточно,
поскольку измерение способностей покрывает всего четыре признака. Полный анализ — в §10 отчёта в
GitHub-репозитории.

`dir_ent.pt` — та же архитектура, обученная с дополнительным штрафом на изменение энтропии
следующего токена. У него удалена примерно половина общей компоненты и то же сравнение на
настоящем тексте при равной доставке концепта;
концепта на единицу силы он доставляет меньше, чем `direction_correction.pt`.

## Как пользоваться поправкой

```python
import torch
from model import load_direction_correction

correction = load_direction_correction("direction_correction.pt")
v_hat = torch.randn(768)
v_hat = v_hat / v_hat.norm()
w = correction(v_hat.unsqueeze(0))[0]
h_tilde = h + s * w
```

`model.py` содержит определение модуля и функцию загрузки. В полной реализации интервенция
применяется ко всем позициям, кроме первых двух, где норма резидуала является выбросом и искажает
оценку масштаба.

Сила задаётся как `s = c · max_activation · ‖W_dec[f]‖`, то есть относительно естественного
масштаба конкретного признака. Поправка обучалась для `c ∈ [0.5, 2.5]`. При `c = 0.5` улучшения
нет; значения выше `c ≈ 3` не проверялись.

## Содержимое

- `direction_correction.pt` — основной артефакт, поправка направления ранга 64 (идентична `checkpoints/dir_hot.pt` в репозитории)
- `dir_ent.pt` — вариант со штрафом на энтропию
- `denoiser.pt` — денойзер резидуала из первого раунда экспериментов
- `model.py` — автономные определения моделей и функции загрузки
- `config.json` — архитектура и замороженные параметры
- `README.ru.md` — эта карточка модели (английская версия: `README.md`)

`direction_correction.pt` и `dir_ent.pt` принимают нормированное направление формы `(..., 768)` и
возвращают направление той же формы с единичной нормой. `denoiser.pt` принимает активацию, у
которой последняя размерность равна 768, и величину возмущения.

## Обучение

Поправка обучалась через замороженную верхнюю половину GPT-2. Для чистой активации `h`,
направления `v` и силы `s` оптимизировался отклик финальных логитов:

```text
L = −A / A_naive + γ · relu(C / C_naive − 1)
```

`A` измеряет сохранённый отклик вдоль малосигнального причинного направления, `C` — относительную
величину нелинейного остатка. Эталонные значения считаются в том же батче с исходным направлением,
поэтому оптимизатор не может получить хорошее значение функции потерь, просто уйдя «в безвредную
сторону» и не доставив признак. Обучение заняло около 4.2 минуты на GTX 1660 Ti с 6 ГБ памяти.
`dir_ent.pt` добавляет `+ 1.0 · mean |H(steered) − H(clean)|` — изменение энтропии следующего
токена через тот же замороженный суффикс.

Денойзер обучался отдельно на активациях OpenWebText с квадратичной функцией потерь
`‖h − D(h + s·u)‖²`. Во всех абляциях использовалось одно и то же распределение энергии шума.

## Контроль утечки

Признаки SAE, использованные для обучения, не пересекаются с признаками, на которых выбирались
параметры и проводилась финальная оценка. Признаки с модулем косинусной близости не меньше 0.3 к
любому оценочному направлению исключены из обучающего словаря. Поправка также проверена на
двенадцати признаках, исключённых из её обучающего пула до финального переобучения, и на ещё
48 признаках, исключённых вместе с их косинусными соседями из переобученного чекпойнта.

## Ограничения

- Проверены только GPT-2 small и один релиз SAE; воспроизведение на втором слое (блок 10) находит
  то же общее направление при более слабом приросте концепта.
- У опубликованного чекпойнта один обучающий сид. На пяти сидах при ранге 64 прирост концепта
  устойчив (0.39–0.46), а выигрыш по перплексии варьируется (от −1.1 до −2.1 ната).
- Оценка опирается на 12–48 признаков, отобранных объективным лексическим правилом.
- Выигрыш по перплексии на сгенерированном тексте по большей части является артефактом
  уверенности, а не улучшением качества текста.
- Во время генерации распределение активаций смещается по мере роста силы, а поправка остаётся
  фиксированным линейным отображением.
- Перенос на другие модели и SAE не проверялся.
